# Leaderstats System

A simple and clean Leaderstats system for Roblox Studio.

## Features

- Coins
- Level
- Kills
- Deaths
- Automatic player setup
- Clean Luau code

## Installation

1. Open Roblox Studio.
2. Insert the script into **ServerScriptService**.
3. Play the game.
